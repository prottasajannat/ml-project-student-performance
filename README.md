## Problem Idea
This project aims to analyze student performance using study hours, sleep hours, attendance, and snack purchases. The goal is to explore patterns that may help predict whether a student will pass or fail.

## Current Dataset Status
The dataset currently contains 6 student records. It is a small sample dataset used for experimentation and learning.

## How to Run the Notebook
Open `notebooks/lab01_setup.ipynb` using Google Colab or Jupyter Notebook and run the cells from top to bottom.

## Results
The results are preliminary and are based on a small sample dataset. Further experiments and more data are required for reliable conclusions.
