## 1. Problem Idea

This project explores student performance using factors such as study hours, sleep hours, attendance, and snack purchases. The goal is to identify patterns in the data and explore whether these factors are related to students' pass or fail outcomes.

---

## 2. Dataset

The current dataset is a small sample containing information about 6 students.

The dataset includes the following features:

- Study Hours
- Sleep Hours
- Attendance
- Snack Purchases

The target label is:

- Passed

The dataset is currently used for learning, experimentation, and preliminary analysis.
